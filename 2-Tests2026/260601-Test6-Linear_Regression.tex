\begin{enumerate}[label=\textbf{P\arabic*.},itemsep=1em]
  \item \textbf{[13 p]} Adapt the Python code you have on your computer to find the values for $\alpha$ and $\beta$ of the least squares line of best fit $Y = \alpha + \beta x$ for the given dataset, where $x$ represents the daily UV-B exposure hours and $Y$ represents the proportion of mice developing skin lesions.

  \item \textbf{[13 p]} Create a single figure containing both a scatter plot of the original dataset points and a plot of your linear regression model $Y = \alpha + \beta x$.

  \item \textbf{[13 p]} Estimate the probability that a mouse exposed to an average of 6.4 hours of daily UV-B radiation will develop skin lesions.

  \item \textbf{[6 p]} To the figure of problem P2., add a point, ideally with a different colour, showing your projection of problem P3.

  \item \textbf{[15 p]} Suppose you propose a different model: a linear model with the same intercept $\alpha$ as the one in P1--P4, but in which the probability that a mouse develops skin lesions grows 70\% faster with respect to $x$ compared to the original model. Plot this new model in the same figure with the scatter plot of the dataset. Using this new model, estimate the number of hours of daily UV-B exposure required for the probability of developing a skin lesion to reach 97\%.

\end{enumerate}


\begin{mysolution}
    \textbf{P1. Least Squares Regression Analysis:}
    Let $x$ be the daily UV-B exposure hours and $Y$ be the proportion of mice developing skin lesions. Using the standard formulas for linear regression coefficients $\beta$ (slope) and $\alpha$ (intercept):
    \[
    \beta = \frac{n\sum (x_i Y_i) - \sum x_i \sum Y_i}{n\sum x_i^2 - (\sum x_i)^2}, \quad \alpha = \bar{Y} - \beta \bar{x}
    \]
    Calculating the summation terms for the $n = 10$ data points yields:
    \begin{align*}
    &\sum x_i = 55.0, \quad \sum Y_i = 3.8660, \quad \bar{x} = 5.5, \quad \bar{Y} = 0.3866 \\
    &\sum x_i^2 = 385.0, \quad \sum x_i Y_i = 30.3630
    \end{align*}
    Substituting these values into our coefficient expressions:
    \[
    \beta = \frac{10(30.3630) - (55.0)(3.8660)}{10(385.0) - (55.0)^2} = \frac{303.630 - 212.630}{3850.0 - 3025.0} = \frac{91.0}{825.0} \approx 0.110303
    \]
    \[
    \alpha = 0.3866 - (0.110303 \cdot 5.5) = 0.3866 - 0.606667 \approx -0.220067
    \]
    Thus, the linear regression model equation is:
    \[
    Y = -0.2201 + 0.1103x
    \]

    \textbf{P2 \& P4. Graphical Representation:}
    The experimental scatter data, the baseline linear regression curve, the predicted value, and the accelerated alternative model are plotted below.

    \textbf{P3. Model-Based Projection:}
    Evaluating the model at an exposure time of $x = 6.4$ hours:
    \[
    Y = -0.220067 + 0.110303(6.4) = -0.220067 + 0.705939 = 0.485872
    \]
    The estimated model-based probability that a mouse develops skin lesions is approximately \textbf{0.4859} (or \textbf{48.59\%}).

    \textbf{P5. Alternative Linear Model with Accelerated Growth:}
    The alternative configuration establishes an identical vertical intercept $\alpha_{new} = \alpha \approx -0.220067$, but a slope increasing by $70\%$:
    \[
    \beta_{new} = \beta \cdot (1 + 0.70) = 0.110303 \cdot 1.7 \approx 0.187515
    \]
    This generates the updated structural expression:
    \[
    Y_{new} = -0.220067 + 0.187515x
    \]
    To find the exposure threshold required for a $97\%$ pathology rate ($Y_{new} = 0.97$), solve for $x$:
    \[
    0.97 = -0.220067 + 0.187515x \implies 0.187515x = 1.190067
    \]
    \[
    x = \frac{1.190067}{0.187515} \approx 6.3465
    \]
    Under this alternative model, the skin lesion probability reaches $97\%$ at approximately \textbf{6.35 hours} of daily UV-B exposure.
